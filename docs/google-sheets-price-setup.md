# Підключення прайсу Status до Google Sheets

Інтеграція працює без Apps Script:

`Google Sheets → Google Visualization read-only feed → price-loader.js → price.html`

Таблиця: [Status — прайс для сайта](https://docs.google.com/spreadsheets/d/1Vg2jk_p9DQV2KJubMuD7pcGXAB-k9WO4JZty5YTxYCU/edit)

Сайт читає тільки три колонки з семи фіксованих вкладок: службовий ID, назву послуги та ціну. Категорії, їхні заголовки, дизайн і швидкі посилання залишаються у HTML сайту.

## 1. Одноразово відкрийте таблицю для читання

Цю дію може виконати тільки власник Google-таблиці.

1. Відкрийте таблицю за посиланням вище.
2. Натисніть **Поділитися** у правому верхньому куті.
3. У блоці **Загальний доступ** виберіть **Усі, хто має посилання**.
4. Праворуч залиште роль **Читач**.
5. Натисніть **Готово**.

Не надавайте публічне право редактора. Клієнта додавайте окремо за його Google-адресою з роллю **Редактор**.

Після цього відвідувачі сайту можуть отримати тільки read-only дані таблиці без входу в Google. Сам сайт не має прав змінювати таблицю.

У таблиці не повинно бути персональних даних пацієнтів, паролів, токенів або внутрішньої медичної інформації. Вона призначена тільки для публічного прайсу.

## 2. Як клієнту редагувати прайс

У таблиці є сім фіксованих вкладок:

- `Загальні`
- `Профілактика`
- `Пародонтологія`
- `Терапія`
- `Ортодонтія`
- `Ортопедія`
- `Хірургія`

У кожній вкладці:

- колонка A — службовий ID, прихована та захищена;
- колонка B — `Назва послуги`;
- колонка C — `Ціна`.

Клієнт працює тільки з B і C.

- **Змінити назву:** відредагувати колонку B потрібного рядка.
- **Змінити ціну:** відредагувати колонку C. Можна вводити повний текст, наприклад `400 грн`, `від 2500 грн` або просто число.
- **Додати послугу:** додати новий рядок у потрібній вкладці та заповнити B і C. Колонку A заповнювати не потрібно.
- **Видалити послугу:** видалити весь рядок.
- **Змінити порядок:** перемістити весь рядок у межах тієї самої вкладки.

Не перейменовуйте сім вкладок і не змінюйте заголовки A1:C1. Категорії не редагуються з таблиці.

Порожні та незавершені рядки сайт ігнорує. Це дозволяє спокійно вводити нову послугу без тимчасового ламання прайсу.

## 3. Як працює сайт

1. `price.html` одразу показує повний статичний резервний прайс.
2. `price-loader.js` звертається до семи фіксованих вкладок через офіційний Google Visualization endpoint.
3. Дані проходять повну перевірку.
4. Тільки після успішної перевірки всі сім списків замінюються одночасно.
5. Якщо таблиця недоступна, закрита, пошкоджена або містить небезпечне значення, статичний прайс залишається на сторінці без технічної помилки для відвідувача.

Назви та ціни вставляються тільки через `textContent`. HTML і JavaScript із клітинок не виконуються.

## 4. Перевірка перед merge

Після ввімкнення доступу **Усі, хто має посилання → Читач** запустіть:

```powershell
node --check price-loader.js
node scripts/test-price-loader.mjs
node scripts/validate-seo.mjs
git diff --check
```

Потім відкрийте тестову версію `price.html` і перевірте:

1. Усі сім категорій відображаються.
2. Зміна тестової назви або ціни в таблиці з'являється після оновлення сторінки.
3. Доданий рядок з'являється у правильній категорії.
4. Видалений рядок зникає.
5. Порядок відповідає порядку рядків у таблиці.
6. При тимчасовому закритті доступу до таблиці залишається статичний fallback.
7. На 360, 768 і 1440 px немає горизонтального overflow.

Після тесту поверніть погоджені назви та ціни.

Merge і deployment залишаються окремими діями та потребують прямого дозволу власника.

## 5. Відновлення помилкової зміни

1. У Google Sheets відкрийте **Файл → Історія версій → Переглянути історію версій**.
2. Знайдіть стан до помилки.
3. Відновіть всю версію або скопіюйте потрібні значення назад.
4. Оновіть сторінку прайсу та перевірте результат.
