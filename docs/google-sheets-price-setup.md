# Підключення прайсу Status до Google Sheets

Ця інтеграція використовує приватну робочу таблицю та публічний Google Apps Script Web App, який повертає тільки ID, назву й ціну послуг із семи дозволених вкладок. Вкладка `Інструкція` та інші файли Google Drive не потрапляють у JSON.

Таблиця: [Status — прайс для сайта](https://docs.google.com/spreadsheets/d/1Vg2jk_p9DQV2KJubMuD7pcGXAB-k9WO4JZty5YTxYCU/edit)

## 1. Додайте Apps Script

1. Відкрийте таблицю за посиланням вище під обліковим записом власника.
2. Оберіть **Розширення → Apps Script**.
3. Відкрийте `Code.gs`, видаліть початковий приклад і вставте весь вміст репозиторного файла `google-apps-script/Code.gs`.
4. Натисніть **Зберегти**.
5. У списку функцій виберіть `setupStatusPriceSheet` і натисніть **Виконати**.
6. Підтвердьте запит Google на доступ до цієї таблиці. Скрипт перевірить усі сім вкладок і заголовки `ID`, `Назва послуги`, `Ціна`, захистить рядок заголовків і колонку A, приховає колонку A та не видалить наявні дані.
7. За бажанням запустіть `testStatusPricePayload` і перевірте журнал виконання. Там мають бути `schemaVersion: 1` і всі сім категорій; вкладки `Інструкція` у відповіді бути не повинно.

Якщо `setupStatusPriceSheet` повідомляє про відсутню вкладку або неправильний заголовок, виправте тільки назву вкладки чи заголовок. Не запускайте масове очищення або перезапис таблиці.

## 2. Опублікуйте Web App

1. В Apps Script натисніть **Розгорнути → Нове розгортання**.
2. Оберіть тип **Вебдодаток**.
3. У полі виконання виберіть **Від мого імені**.
4. У полі доступу виберіть **Усі** (`Anyone`), щоб статична сторінка могла отримати публічний прайс без входу в Google. Сама таблиця при цьому не публікується.
5. Натисніть **Розгорнути**, підтвердьте дозволи та скопіюйте URL, який закінчується на `/exec`. Не використовуйте тестовий URL `/dev`.

Web App повертає лише дані прайсу. Не додавайте до коду токени, паролі, аналітичні секрети або персональні дані пацієнтів.

## 3. Вставте URL у сайт

Відкрийте `price-loader.js` і замініть значення константи `PRICE_API_URL` на скопійований `/exec` URL. Це єдине місце налаштування endpoint у коді сайту.

Після зміни URL перевірте синтаксис і тести:

```powershell
node --check price-loader.js
node scripts/test-price-loader.mjs
node scripts/test-google-apps-script-price.mjs
node scripts/validate-seo.mjs
git diff --check
```

Потім зміна має пройти звичайний review, merge і deployment GitHub Pages. Ця інструкція не надає дозволу на merge або deployment.

## 4. Перевірте JSON і сторінку

1. Відкрийте `/exec` URL у приватному вікні браузера. Має відобразитися JSON із `schemaVersion: 1`, `updatedAt` і сімома ключами в `categories`.
2. Переконайтеся, що JSON не містить `Інструкція`, формул, приміток або інших вкладок.
3. Відкрийте `price.html` після дозволеного deployment. Спочатку сторінка показує статичний резервний прайс, потім непомітно замінює тільки рядки послуг перевіреними даними з Web App.
4. Тимчасово змініть тестову назву або ціну в таблиці, оновіть сторінку та перевірте результат. Після тесту поверніть погоджене значення.
5. Якщо Web App недоступний, URL не налаштований, відповідь пошкоджена або дані не проходять перевірку, сторінка не показує помилку відвідувачу й залишає статичний прайс без змін.

## 5. Як клієнту редагувати прайс

- **Змінити назву:** відредагуйте колонку B потрібного рядка.
- **Змінити ціну:** відредагуйте колонку C. Вказуйте повний видимий текст, наприклад `400 грн` або `від 2500 грн`.
- **Додати послугу:** додайте рядок у потрібній категорії та заповніть B і C. Колонку A не відкривайте й не редагуйте: `onEdit` автоматично створить стабільний ID. Якщо тригер не спрацював одразу, перший успішний запит Web App також додасть ID.
- **Видалити послугу:** видаліть увесь її рядок. Після оновлення сторінки послуга зникне з динамічного прайсу.
- **Змінити порядок:** перемістіть увесь рядок у межах тієї самої вкладки. Порядок рядків у таблиці є порядком послуг на сайті.

Не перейменовуйте сім вкладок і не змінюйте заголовки A1:C1. Категорії, заголовки секцій та швидкі посилання керуються HTML сайту, а не таблицею.

## 6. Відновлення помилкової зміни

1. У Google Sheets відкрийте **Файл → Історія версій → Переглянути історію версій**.
2. Знайдіть стан до помилки.
3. Або відновіть всю версію, або скопіюйте потрібні значення назад у поточну таблицю.
4. Перевірте `/exec` JSON, а потім сторінку прайсу.

Якщо змінювався сам `Code.gs`, створіть нову версію через **Розгорнути → Керувати розгортаннями → Редагувати**. Звичайні зміни назв, цін, рядків і порядку нового розгортання Apps Script не потребують.
